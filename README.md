# IAESTE India LC JECRC — Website Redesign

A modern, responsive website redesign for IAESTE India Local Committee JECRC.

## Project Links

- **Live Website:** https://iaeste-lc-jecrc-redesign-akay10.vercel.app
- **GitHub Repository:** https://github.com/spidyyakay1022/IAESTE-LC-JECRC-Redesign

## Features

- Modern, user-friendly home page
- Organised department grid covering seven departments
- IAESTE-inspired blue, white and red visual theme
- Responsive navigation and layouts for desktop and mobile
- About, benefits, team and membership sections

## Tech Stack

- React
- Vite
- React Router
- Lucide React
- CSS

## Run Locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
